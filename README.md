# tinyworld

A small virtual village where autonomous NPCs perceive the world, remember events, pursue goals, communicate, and change the world over time.

## Architecture

**Build the world first. No LLM. Deterministic.**

The first version will be fully deterministic. NPCs will have explicit rules for perception, memory, goals, decisions, and actions.

The goal is to make the simulation interesting **without AI-generated behavior**.

> **Build the world first. Add intelligence later.**

LLMs can eventually be added as a reasoning layer, not as the foundation of the simulation.
